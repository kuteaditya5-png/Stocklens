Before connecting

  1. Deploy the StockLens OAuth update to the production site.
  2. Create an Upstox Algo Trading App with the exact callback shown above.
  3. Set UPSTOX_API_KEY, UPSTOX_API_SECRET, UPSTOX_REDIRECT_URI, STOCKLENS_OAUTH_SECRET, and your existing STOCKLENS_ACCESS_KEY in Vercel's Production environment.
  4. Redeploy, click Connect with Upstox, and log in on Upstox's official page.

Never share API secrets, access tokens or OTPs. This starter uses a sealed browser cookie, not an always-on backend token vault. Automatic CE/PE entries, multiple exit orders, trailing stops and static-IP broker execution are not enabled or implemented in this release. A separate hardened trading server, persistent encrypted credential storage, static IP registration and broker sandbox tests will be needed before any real orders.
